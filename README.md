# Сімейний бюджет

Калькулятор спільного сімейного бюджету: доходи → десятина → розподіл по статтях («конвертах»), облік витрат за місяць, розстрочки, цілі накопичень і банки monobank. Працює разом з агентом у Telegram ([budget-agent](https://github.com/jacobs121312/budget-agent)): після «Підключити агента» дані однакові на всіх пристроях.

Сайт: https://jacobs121312.github.io/budget-app/

## Вкладки

- **План** — доходи, десятина, статті з лімітами, розстрочки (залишок, день платежу, коли закриються), цілі (сума, дата, накопичено, доларова готівка), перевірка 50/30/20.
- **Витрати** — скільки лишилось за місяць, ліміт на день, прогрес кожної статті, запис витрати, історія місяців.
- **Банки** — що зробити кожному в день зарплати: скільки в яку банку і що лишити на картці.

## Розробка

React + TypeScript + Vite + Tailwind + [shadcn/ui](https://ui.shadcn.com).

```bash
npm install
npm run dev      # http://localhost:5173/budget-app/
npm run build    # збирає dist/
```

Push у `main` збирає й публікує сайт через GitHub Actions (`.github/workflows/pages.yml`).

Правила розрахунку (`src/lib/budget.ts`) повторюють агента (`budget-agent/src/budget.js`, `payday.js`) — змінюйте обидва місця разом.
